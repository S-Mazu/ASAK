# **ASAK** (Admin's Swiss Army Knife)
PowerShell 7 tooling for machine management and information gathering on Windows.

## Requirements

- **PowerShell 7.6 LTS or later** must be installed on the target machine.
- **Administrator privileges** are required to run ASAK.

## Install

- Copy the **ASAK** folder to a USB stick or any local folder. No installer is required.

## Usage

- Run **ASAK.ps1** as **Administrator**.
- Select a task from the menu.
